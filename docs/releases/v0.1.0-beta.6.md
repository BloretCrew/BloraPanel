# Blora Panel v0.1.0-beta.6

**Prerelease for hands-on evaluation, not a stable release.**

## Changes since beta.5

- Replaces the browser's native right-click menu in the node file manager with a built-in file-operation menu.
- Right-clicking an item selects it and offers open, create, upload, cut/copy/paste, rename, move, copy, trash, download, compress, extract, and refresh actions.
- Existing confirmation dialogs, node authorization, version checks, and durable task handling continue to guard file mutations.

## Validation boundaries

The file-manager browser suite passes 6/6, frontend type checking passes, and the production web build succeeds. Windows packages are cross-compiled; no new Windows device run is claimed. This prerelease does not claim stable-release readiness.
