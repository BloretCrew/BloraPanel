# Blora Panel v0.1.0-beta.7

**Prerelease for hands-on evaluation, not a stable release.**

## Changes since beta.6

- File-manager right-click handling now runs during event capture, preventing the browser's native menu even when an inner file element stops propagation.
- Replaces the previous synthetic-only regression check with a real Chromium right-click and a propagation-stopping target.

## Validation boundaries

The file-manager browser suite, frontend type checking, and production build are run for this release. This prerelease does not claim stable-release readiness.
