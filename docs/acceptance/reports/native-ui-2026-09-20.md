# 原生桌面 UI 重写验证

日期：2026-09-20。按用户提供的 macOS 参考图重写，取代上一轮仅改配色的方案。

## 实际变更

- 删除 `web/src/desktop-light.css`，完全重写 `web/src/style.css`；应用内容使用新 `web/src/applications.css`，不再叠加旧主题。
- 菜单栏承载账号、通知、现场保护和时间；底部改成图标 Dock，应用名只在悬停/键盘聚焦时提示，保留运行点、多窗口数量和窗口选择。
- 窗口控制统一为左侧红黄绿圆点及同组 SVG 符号，保留关闭、最小化、最大化/还原、八向缩放与标签拖放。
- 13 个应用图标与应用库图标重新绘制，使用文件夹、服务器、纸笔、磁盘、购物袋等独立轮廓。SVG 渐变通过 useId 隔离。
- 实例中心和文件管理器改成侧栏、紧凑工具栏与资源列表；其余应用换成统一表单、列表、分隔线与状态样式。应用市场保持桌面与 Dock 入口及原有权限。
- 新增本地 SVG 风景桌面背景。登录采用简洁系统对话框。桌面与窄屏响应式均检查。

## 验证与边界

- `cd web && npm run build`：退出0，类型检查和 Vite 构建通过。
- `cd web && npm test -- --run`：47/47 通过。
- `cd web && npm run test:e2e`：首轮35通过、1因实例设置与Dock设置同名而定位歧义失败；限定资源导航定位后，`instance-settings.spec.ts` 1/1复验通过。合计36个场景验证通过，未减少断言；不是一次整组36/36。涵盖窗口恢复、编辑器、文件虚拟列表、权限、实例控制、扩展安装与状态恢复。
