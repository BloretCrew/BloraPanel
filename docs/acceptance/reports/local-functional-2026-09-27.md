## 产品修复

Compose 配置 prepare/chunk/content/commit 原先在查询权限前解析 requestId/参数，未授权且缺幂等键的请求会得到400。现在先验证节点与 `host.manage` 权限，再解析请求，实际执行时重查权限。新增无键/无效参数的403回归，保留管理员缺键400及已有保存事务。真实 Docker 分阶段配置保存、Daemon重启后读取、显式apply与权限回归通过（Go用例8.332s，命令15.160s、退出0）。

桌面原先按焦点顺序移动已有窗口 DOM，浏览器会重载其中的 iframe，从而丢失扩展未提交本地输入、取消正在点击的按钮。现在窗口 DOM 保持创建顺序，焦点只更新已有 CSS z-index。新增真实沙箱输入/三次焦点切换/启动身份与点击计数验证已通过；保留原有开窗、移窗、关闭及工作区恢复语义。
