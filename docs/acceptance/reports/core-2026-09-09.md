## 三进程浏览器联调环境

```sh
make build
env GOFLAGS=-buildvcs=false GOCACHE=/tmp/blora-go-build GOMODCACHE=/tmp/blora-go-mod GOPATH=/tmp/blora-go go build -o dist/blora-devfixture ./cmd/devfixture
./dist/blora-devfixture
```

实际启动 URL `https://127.0.0.1:9443`。工具创建新的 `.local/fixture-*` 目录、独立 Master 二进制和两个 Daemon 二进制。密码每次随机生成，只写权限0600的 `browser-credentials.json`，终端仅打印路径；没有可复用的生产默认密码。两个实例初始停止，成员查看两者，仅对第一个获得部分控制和文件写权限，没有主机Shell或创建权限。

停止 fixture 时，工具先请求强制停止自身两个测试实例，再关闭三个自身进程；不会清理其他宿主机对象。目录和日志保留供诊断，实际当前会话及目录见 PROGRESS。浏览器测试应读取该私有文件，不打印凭据。测试自签证书例外只用于浏览器测试上下文，节点连接继续验证CA。
