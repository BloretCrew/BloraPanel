## Candidate architecture

- Shared wallpaper-only optical raster replaces recursive per-window backdrop filters. The material still has the selected palette, tint and blur; overlapping windows now sample the wallpaper instead of other applications. Live application or extension content is never captured in the cache. Unsupported wallpaper/canvas paths retain the original filter as fallback.
- Window gestures draw geometry imperatively and commit the recovery state on release, cancellation or reload. Rerenders during a held gesture retain the drawn rectangle; old queued gestures are cancelled.
- Window draw coordinates are being evaluated on physical display pixels to avoid repeated fractional resampling; HiDPI keeps sub-CSS-pixel precision.
- Current candidate encodes an already opaque desktop raster without an unnecessary alpha plane, and conservatively clips application paint to the bounds of actually exposed regions. Opaque coverage is established only by solid mode or a successfully cached opaque wallpaper. Rounded corners and antialiased edges never establish coverage. The algorithm keeps one bounding rectangle, falls back to full paint for pathological arrangements, and observes only window geometry/visibility changes rather than terminal DOM output.
- Layout geometry is cached across pure translations and invalidated by bounded structural/size observers and actual tab activation. During a gesture, the body exposure envelope only expands conservatively; release restores the exact conservative bound. Drag commit resynchronizes optical planes even when the already drawn transform does not change.
- WebKit-specific visibility defect was reproduced by the independent native `.xterm-screen` observer: both `clip-path` and legacy CSS `clip` leave it intersecting despite visual clipping. Neither is accepted as pausing rendering. The replacement uses a stable flex layout region, an overflow paint viewport and a dimension-preserved xterm host. Only the viewport collapses while fully covered; real host dimensions continue following region layout, without stopping streams/parser/checkpoints or changing leases. The strict covered-output/reload/notice-layout regression passed on WebKit, 1/1 in 18.9 s. Complete-load performance remains pending.
