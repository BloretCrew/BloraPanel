# 文件目录树增量验收（2026-09-22）

本轮补齐文件管理器规划中的目录树入口。树只读取当前实例授权目录；根目录和用户展开的目录各请求一个首分页块，未展开的目录不会递归拉取。展开路径保存在文件视图状态中，刷新后按原路径重新加载；点击目录仍复用路径历史、选中项和滚动恢复逻辑。

实现位置：`web/src/apps/FilesApp.vue` 的 `treeExpanded`、`tree`、`treeRows` 与目录树模板；样式位于 `web/src/applications.css`。目录树不改变服务端文件操作授权，文件列表仍使用带版本的分页读取。

## 验证

- `npm run check`：通过。
- `npm run test:e2e -- tests/browser/files.spec.ts`：5/5 通过（16.7s）。新增场景验证根目录、`alpha`、`alpha/beta` 的按需请求，导航到孙目录后正文列表正确，刷新后目录路径与展开分支恢复；原有 10,000 项虚拟分页、上传续传、取消回执和目录快捷方式场景同步通过。

## 边界

目录树每个展开节点只显示首个分页块；超出首块的目录内容仍在主列表中按版本分页，不在侧栏无限展开。没有目录项类型元数据时，目录项允许尝试展开空目录；节点返回空页后保持为空。移动端现有窄屏规则继续隐藏侧栏，主列表和路径导航仍可用。
