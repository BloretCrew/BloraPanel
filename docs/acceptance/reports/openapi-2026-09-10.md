# 管理 API OpenAPI 交付描述

新增 [`docs/api/openapi.yaml`](../../api/openapi.yaml)，以 OpenAPI 3.1 描述 HTTPS Master 管理接口。文档覆盖 96 个路径、110 个操作，包含 session cookie、`X-CSRF-Token`、`Idempotency-Key`、结构化错误、审计检索、任务状态、节点/实例、文件/终端、Docker/Compose、备份/调度、监控、有限系统管理、扩展和云端工作区。任务中心还描述了失败/中断的实例生命周期任务重试入口及关联任务回执。

验证命令：

```sh
python3 - <<'PY'
import yaml
with open('docs/api/openapi.yaml', encoding='utf-8') as f:
    spec = yaml.safe_load(f)
assert spec['openapi'] == '3.1.0'
paths = spec['paths']
operations = sum(1 for item in paths.values() for method, value in item.items() if method in {'get','post','put','patch','delete'})
assert len(paths) == 96 and operations == 110
print(spec['openapi'], len(paths), operations)
PY
```

结果：解析输出 `3.1.0 96 110`，退出码 0。README 已链接此合同；具体响应正文仍以对应应用的真实 Master 处理器为准。
