# 文件管理器图标/列表视图增量验收（2026-09-22）

文件管理器现在提供可恢复的“列表 / 图标”视图切换。列表视图继续使用原有按滚动窗口读取的虚拟列表，适合万条目录；空白区域可拖出框选范围；图标视图按节点分页读取，每页最多 100 项，并提供上一页/下一页。当前视图和图标页码写入文件视图现场，刷新不会回到另一种视图或重复执行文件操作。

实现位置：`web/src/apps/FilesApp.vue` 的 `viewMode`、`gridOffset`、图标视图模板和分页动作；样式位于 `web/src/applications.css`。两种视图共享选择、双击打开、拖放、剪贴板和目录权限模型；图标视图只改变呈现和分页，不绕过节点版本校验。

## 验证

- `npm run check`：通过。
- `npm run test`：11 个文件、63/63 通过。
- `npm run build`：通过。
- `npm run test:e2e -- tests/browser/files.spec.ts`：5/5 通过（19.0s）。新增场景验证列表空白区域框选、10,000 项目录从列表切换到图标、分页到第 101 项、刷新后仍保持图标页，再切回列表继续搜索和排序；目录树、上传续传/取消与桌面目录快捷方式同步通过。

## 边界

图标视图按页展示当前目录首层条目；大目录的连续滚动和虚拟化仍由列表视图提供。两种视图都受同一实例授权、目录版本和文件任务回执约束。
