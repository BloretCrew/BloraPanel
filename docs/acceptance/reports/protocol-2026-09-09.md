# 协议模块验证记录

时间：2026-09-09 05:36 UTC；环境：Linux 6.19.12-200.fc43.x86_64 / amd64，Go 1.25.9 X:nodwarf5。依赖 coder/websocket v1.8.14、google.golang.org/protobuf v1.36.11，按根 go.mod 锁定。

实现范围：B01/B03 协议基础，关联 F04、A05、A08、A09 的协议子场景。代码：`internal/protocol`、`api/management.proto`；接入说明：`internal/protocol/README.md`。

实际运行命令：

```sh
env GOCACHE=/tmp/blora-go-build GOMODCACHE=/tmp/blora-go-mod GOPATH=/tmp/blora-go go test -race -count=1 -v ./internal/protocol
env GOCACHE=/tmp/blora-go-build GOMODCACHE=/tmp/blora-go-mod GOPATH=/tmp/blora-go go test ./internal/protocol -run '^$' -fuzz FuzzUnmarshal -fuzztime=5s -parallel=2
```

第一条最终退出码 0，输出 `ok blora.dev/panel/internal/protocol 1.173s`；真实 `httptest.NewTLSServer`，客户端信任测试 CA，未关闭 TLS 校验。通过以下针对性验证：

| 测试 | 验证事实 |
| --- | --- |
| TestProtobufInteroperability | `.proto` 字段合同与官方动态 Protobuf 双向编码互操作，未知兼容字段可读取 |
| TestMalformedFrames | 重复字段、溢出、错误 wire type、零 tag、截断、group、消息尺寸上限拒绝 |
| TestFlowCreditAndReplay | 单流/全连接窗口、重复 ACK 不增加额度、未来 ACK、重复 DATA、部分消费和预算释放 |
| TestChallengeBindsIdentityConnectionAndExpiry | 节点、连接、nonce、代次、通道、版本、过期任一改变均无法通过签名验证 |
| TestWSSReadWriteAndGenerationFence | TLS 上真实二进制双向读写；被替换代次不能继续写入 |
| TestWSSFlowAcknowledgesConsumptionOnly | socket 读取不恢复额度；消费者调用 Consume 后通过真实 ACK 恢复 |
| TestWSSRejectsCrossChannelStaleMalformedAndOverflow | 旧代次、跨物理通道、文本帧、超大帧、接收额度违规均终止连接 |
| TestSeparateBulkCannotStarveControl | 无消费者的批量队列达到字节/条目边界关闭，而独立控制连接仍收发停止请求 |
| TestCursorRequiresSnapshotAfterGap | 快照前拒绝事件、重复事件忽略、缺口必须重取快照、已裁剪恢复区间拒绝 |
| TestCancelledReadKeepsSessionAndCancelledSendDoesNotSubmit | 本地取消读保持远程连接；提交前已取消的发送不产生消息 |
| TestBulkRateWaitHonorsWriteDeadline | 批量令牌额度耗尽后，等待在写入截止期限内终止 |

第二条退出码 0，实际执行 55,162 次 fuzz 输入，新增 58 个覆盖样本，总 60 个，未发生崩溃或非法往返；输出 `ok blora.dev/panel/internal/protocol 6.013s`。这是短时针对性 fuzz，不能声称穷尽全部输入空间。

真实失败及修复：首次在沙箱运行 TLS 测试，监听本机临时端口被拒绝：`listen tcp6 [::1]:0: socket: operation not permitted`，因此申请并获准后在允许本机监听的环境重跑。新增速率测试首次遇到裸测试客户端 websocket 默认 32 KiB 读取上限，报 `message too big: read limited at 32769 bytes`；按合同显式设为 1 MiB 后重跑通过。生产 Conn 从创建开始设置对应通道读取上限。

未覆盖整体验收：此报告不证明两用户/两节点授权链路完成，不证明 Master nonce 原子消费、节点身份轮换吊销持久化、浏览器 xterm 实际消费回调、文件持久化 ACK、长时间日志磁盘配额或 E08 性能通过。这些仍需主工程集成验证；本模块仅提供真实可运行的边界与辅助合同。测试仅创建本机临时监听器与内存随机身份，清理函数关闭全部连接和测试服务器，没有生产节点或外部部署。
